## 역량과 적용 사례

- 게임 개발의 기초 로직을 익히고 프로그래밍에 입문하기 위해 스크래치를 활용하여 소코반 퍼즐 게임을 제작했습니다. 스크래치는 블록 코딩 기반의 직관적인 인터페이스를 제공하여 프로그램의 전체적인 구조를 시각적으로 파악하고 논리력을 기르기에 적합한 도구입니다. 이 도구를 실제 사례에 적용하여 캐릭터의 상하좌우 이동, 벽과 같은 장애물 충돌 인식, 그리고 지정된 목적지로 박스를 정확히 밀어 넣는 소코반 특유의 퍼즐 상호작용을 단계적으로 구현했습니다. 특히 플레이어의 조작에 따라 게임 내 오브젝트들이 어떻게 반응해야 하는지 조건문과 반복문을 통해 직접 설계하는 과정에 집중했습니다. 결과적으로 이 프로젝트는 단순한 게임 완성을 넘어, 텍스트 위주의 복잡한 코딩을 다루기에 앞서 소프트웨어의 작동 원리와 알고리즘의 흐름을 이해하고 게임 로직 설계의 실무적인 기반을 다지는 의미 있는 경험이 되었습니다.

## 활동 시기와 진행 상태
- 대표적인 활동으로 유니티 기반의 미니게임 제작 프로젝트를 꼽을 수 있습니다. 본 프로젝트는 2023년 4월에 기획 및 개발을 시작하여 약 5개월간 집중적으로 진행되었으며, 같은 해 8월에 모든 핵심 기능 구현과 최종 테스트를 마치고 현재 성공적으로 완료된 상태입니다.

## 활동 목적
- 이 프로젝트를 통해 달성하고자 했던 가장 핵심적인 목표는 유니티 엔진의 전반적인 구동 원리를 숙지하고 게임 개발에 필수적인 C# 프로그래밍 로직을 깊이 있게 체득하는 것이었습니다. 단순한 실습을 넘어 하나의 온전한 미니게임을 처음부터 끝까지 기획하고 완성해 봄으로써, 유니티의 컴포넌트 기반 아키텍처와 게임 오브젝트의 라이프사이클을 실전에서 어떻게 다루어야 하는지 체계적으로 이해하고자 했습니다. 특히 C# 스크립트를 직접 작성하며 플레이어의 입력 처리, 캐릭터의 이동 및 충돌 판정, 그리고 게임 상태 관리와 같은 세부적인 상호작용 로직을 스스로 설계하고 구현하는 데 집중했습니다. 결과적으로 이 과정은 머릿속의 아이디어를 논리적인 코드로 변환하는 능력을 기르고, 객체 지향 프로그래밍에 기반한 효율적인 코드 작성법과 문제 해결 과정을 생생하게 경험하는 탄탄한 밑거름이 되었습니다.

## 본인 역할과 기여 범위
- 본 미니게임 제작 프로젝트는 팀 단위가 아닌 1인 개인 활동으로 진행되었습니다. 따라서 아이디어 기획 단계부터 최종 테스트에 이르기까지 게임 제작에 필요한 모든 과정을 전적으로 홀로 수행했습니다. 구체적으로는 미니게임의 핵심 규칙과 레벨을 설계하는 기획 작업부터, 플레이어의 조작과 물리 엔진 기반의 충돌 로직을 구현하는 C# 스크립트 프로그래밍, 그리고 화면 UI 구성과 시각적 에셋 배치에 이르는 전반적인 개발 업무를 모두 직접 총괄했습니다. 하나의 게임이 기획되어 완성되기까지의 전체 파이프라인을 처음부터 끝까지 온전히 제어해 봄으로써, 기획 의도를 실제 동작하는 코드로 구현해 내는 독립적인 책임감과 종합적인 개발 역량을 깊이 있게 기를 수 있었습니다.

## 수행 과정과 선택 이유
- 본 프로젝트는 기획, 개발, 점검이라는 체계적인 세 단계를 거쳐 진행되었습니다. 기획 단계에서는 미니게임의 전반적인 규칙과 레벨 디자인을 구상하고 필요한 에셋을 정리하여 개발을 위한 구체적인 청사진을 마련했습니다. 이어진 개발 단계에서는 기획한 내용을 바탕으로 직접 C# 스크립트를 작성하여 플레이어 조작, 장애물 충돌 처리, 게임 상태 관리 등 핵심적인 게임 로직을 구현했습니다. 마지막 점검 단계에서는 반복적인 플레이테스트를 통해 동작 오류를 수정하고 전반적인 난이도와 조작감을 세밀하게 조율하여 게임의 완성도를 한층 끌어올렸습니다. 이 모든 과정을 주도할 핵심 개발 도구로 유니티를 선택한 이유는 직관적인 시각적 에디터와 강력한 컴포넌트 시스템을 제공하여 1인 개발자가 전체 파이프라인을 효율적으로 관리하기에 가장 적합했기 때문입니다. 무엇보다 객체 지향적인 C# 코드를 작성하고 그 결과가 게임 내 오브젝트에 실시간으로 어떻게 반영되는지 즉각적으로 확인할 수 있어, 단기간에 엔진의 구동 원리를 깊이 있게 이해하고 프로그래밍 로직을 체화하려는 당초의 목표를 달성하는 데 최적의 환경을 제공해주었습니다.

## 산출물과 결과 설명
- 이 프로젝트의 최종 산출물은 C# 스크립트와 유니티 엔진을 활용해 완성한 소코반 퍼즐 게임의 실제 플레이 화면입니다. 이 산출물은 기획 단계에서 구상했던 퍼즐 메커니즘이 실제 게임 환경에서 오류 없이 작동하는지 시각적이고 기술적으로 직접 확인한 결과물입니다. 구체적으로는 캐릭터가 제한된 맵 안에서 상하좌우로 이동하며 벽면과의 충돌을 인식하고, 흩어진 상자들을 밀어 모든 목표 지점에 정확히 배치하면 스테이지가 클리어되는 핵심 게임 로직을 구현해 냈습니다. 이를 통해 유니티의 충돌 판정 컴포넌트와 오브젝트의 위치 좌표 제어 시스템이 C# 코드를 통해 어떻게 유기적으로 연결되는지 입증했으며, 개발 과정에서 작성된 스크립트 구조와 플레이테스트 기록은 게임 오브젝트 간의 상호작용 원리를 성공적으로 체화하고 문제를 해결해 낸 과정을 보여주는 객관적인 실습 문서로서의 의미를 지닙니다. ## 학습 결과와 개선 방향
- 이번 미니게임 제작 과정을 통해 게임의 장르적 특성에 맞는 최적의 로직 설계가 얼마나 중요한지 깊이 깨달았습니다. 초기에는 유니티의 자체 물리 엔진과 충돌 처리 기능을 주로 활용하여 캐릭터와 상자, 벽의 상호작용을 구현하려 했으나, 소코반과 같이 격자 단위로 정확하게 움직여야 하는 퍼즐 게임에서는 이 방식이 잦은 연산 처리를 요구하고 미세한 위치 오차나 예기치 않은 물리 버그를 발생시킬 수 있다는 한계를 확인했습니다. 이 과정을 겪으며 맵의 전체 상태와 각 오브젝트의 좌표를 2차원 배열과 같은 데이터 구조로 관리하고 논리적으로 통제하는 방식이 물리 연산보다 훨씬 효율적이고 안정적이라는 점을 명확히 배웠습니다. 이러한 실무적 깨달음을 바탕으로 향후 진행할 다음 프로젝트나 유사한 타일 기반 게임을 개발할 때에는 충돌 컴포넌트에 전적으로 의존하기보다, 배열 기반의 상태 관리 시스템을 코어 로직으로 먼저 도입하여 게임 연산의 정확성과 코드의 최적화를 한층 더 끌어올리는 방향으로 아키텍처 설계를 개선할 계획입니다.
