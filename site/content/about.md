## 소개

안녕하세요, 전북대학교(JBNU)에 재학 중인 junho입니다.

## 관심 분야와 선택 이유

12살에 Scratch로 처음 게임 개발을 접한 이후 현재까지 꾸준히 게임 제작을 계속해오고 있으며, 최근에는 Unity C#을 중심으로 개발 환경을 확장하여 시스템 설계부터 메카닉 구현까지 구체화하는 작업에 집중하고 있습니다.

본인의 주요 관심 분야는 게임 시스템 설계와 핵심 메카닉 구현입니다. 어린 시절 Scratch로 프로그래밍의 기초를 접하며 머릿속으로 상상하던 규칙과 상호작용을 화면 위에 직접 구현해 내는 것에 매료되었고, 그 성취감이 지속적인 제작으로 이어졌습니다. 단순한 그래픽 요소를 넘어서 플레이어의 조작감이 게임의 재미를 어떻게 극대화하는지 고민하고, 이를 C# 스크립트로 정교하게 설계하여 탄탄한 게임 루프를 완성하는 과정에 깊은 흥미를 느끼고 있습니다.m

## 학습 목표와 실행 계획

- 목표는 Unity로 게임 1개를 완성하는 것입니다. 이를 위한 향후 학습 목표는 Unity C# 스크립팅 기초 습득 및 플레이어 조작과 물리 엔진 구현입니다. 게임의 기본 동작 프레임워크를 직접 구축하기 위해 C# 기본 문법과 Unity의 물리 컴포넌트를 활용하는 핵심 메커니즘을 익히게 됩니다.

이를 위해 수행할 구체적인 다음 행동은 첫째, Unity Hub와 최신 LTS 버전 에디터를 설치하고 Visual Studio 등의 개발 환경을 연동하는 것입니다. 둘째, 2D나 3D 롤러볼 또는 플래피 버드 류의 기본 튜토리얼 프로젝트를 직접 제작하며 입력 시스템을 이용해 캐릭터 이동 스크립트를 작성합니다. 셋째, Rigidbody와 Collider 컴포넌트를 추가하고 충돌 이벤트를 활용해 아이템 수집 및 장애물 충돌 로직을 구현합니다. 마지막으로 점수 표시용 UI 텍스트를 배치하고 게임 오버 및 재시작 로직을 완성하여 하나의 완전한 게임 루프를 구축합니다.

## 역량과 적용 사례

- C#을 활용하여 게임 내 핵심 로직과 시스템을 구축하고 있습니다. 예를 들어 C#의 객체지향 프로그래밍 개념과 유니티 API를 연동하여 플레이어의 입력 처리부터 이동, 점프, 충돌 감지까지의 물리 상호작용을 담당하는 플레이어 컨트롤러 스크립트를 직접 작성하고 있습니다. 이 과정에서 C#의 이벤트와 델리게이트를 활용하여 플레이어가 아이템을 획득했을 때 점수 관리 시스템과 UI 텍스트가 유기적으로 연동되도록 모듈식 게임 로직을 구현하는 데 적용하고 있습니다.
